# THASSA — Study Studio

A lightweight, local-first study workspace featuring **flashcards and a Pomodoro focus timer**. It runs in any modern browser with no account, backend, or paid API.

## Why this edition exists
The referenced [hAcKeR.app repository](https://github.com/ishaands12/hAcKeR.app) contains *only a README describing a separate macOS desktop app*. No application source code or downloadable binary is available in that repository. This THASSA edition is a **new, openly inspectable browser-based educational prototype**, not a clone of or replacement for that unpublished desktop application.

## Features
- Paste `term: definition` notes and create interactive flashcards.
- Shuffle, flip and navigate cards using buttons or arrow keys.
- Use a 25-minute focus timer or a 5-minute break timer.
- Keep notes in browser localStorage. No tracking or server uploads.
- Responsive layout and accessible button labels.

## Run
Open `index.html` in a browser. No installation needed. For a local dev server, run `python -m http.server 8000` and visit http://localhost:8000.

## Test
Run `node test-flashcards.js` and `node --check app.js`.
